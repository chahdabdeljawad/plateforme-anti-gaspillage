# Plateforme Anti-Gaspillage Alimentaire

## Description
Ce projet a pour objectif de réduire le gaspillage alimentaire en mettant en relation :

- Administrateur
- Supermarchés
- Projets alimentaires
- Clients
- Livreurs

La plateforme permet :
- L’ajout de produits avec date d’expiration
- La réduction automatique des prix
- La gestion des commandes
- La gestion des livraisons
- Un tableau de bord administrateur

## Technologies utilisées
- Frontend : Flutter
- Backend : node.js
- Base de données : PostgreSQL

## Méthodologie
Gestion du projet avec la méthode Scrum via Jira.
